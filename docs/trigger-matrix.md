## 测试程序

1. 新开会话，逐条输入上表语句。
2. 正例：确认触发、确认先收画像字段（或缺字段时明示）、确认报告含置信度标记与免责。
3. 负例：确认无评估流程输出、确认边界说明存在。
4. 正例触发率 <100% 或负例误触发 >0 → 重写 description 的触发词/负例边界 → 重测。
5. 跳过 gates 的实例（如 CLB 5 却输出分数）= 严重缺陷，立即修。

## 已知边界（预期行为记录）

- 澳洲 189/190/491、德国机会卡、NIV/J-Skipper：信息层回复（❔），不做评估。
- 法语 NCLC 换算：收集法语成绩后告知「未入库」，不做 NCLC 自动换算。
- cutoff 种子数据标注待复核：gap 展示时注明数据时点。
