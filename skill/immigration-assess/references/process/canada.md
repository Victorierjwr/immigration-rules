# 加拿大 Express Entry 流程与准备（◐ 已溯源）

> 数据源：`rules/canada/process.yaml`（2026-10-29 核对）。阶段时限为经验估计，非官方 SLA。

## 阶段

1. **入池前准备**（约 2-6 个月）：语言考试（CLB 7 底线）、ECA 学历认证、文档收集
2. **创建 EE 档案**（数天）：IRCC 账户 → 填 profile → CRS 锁定入池
3. **等待邀请**（数月-1 年）：类别轮每周发生；按轮次类型×类别看 cutoff
4. **ITA 后 60 天**：递交申请（体检、指纹、补充材料、缴费）
5. **审批与 PR 卡**（约 6 个月）：背景调查 → 批准 → 登录领卡

## 四层材料清单

- 通用：护照、语言成绩、工作推荐信、无犯罪证明、出生公证
- 国别：ECA 报告、资金证明（按家庭规模，金额随年度更新——见官方页）、定居计划
- 通路：ITA 60 天材料、体检表、指纹、申请费（CAD 950 + PR 权费 575，待复核）
- 画像条件项：已婚 → 配偶材料；有子女 → 子女材料；加拿大工作经历 → 雇主信/税单

## 常见拒因

材料不全（60 天窗口）、雇佣记录矛盾、资金不足。

## 关键提示

- 2026-11-03 起加拿大工作经验与 job offer 加分重构（LMIA 取消）——见规则库 `pending_changes` 与 `regime_switch`。
- 法语类别轮 NCLC 7 全四项；职业列表类（医疗/技工/STEM/教育/交通）需对照官方 NOC 清单。
