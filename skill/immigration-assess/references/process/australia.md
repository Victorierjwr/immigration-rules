# 澳洲技术移民（189/190/491）流程与准备（◐ 已溯源）

> 数据源：`rules/australia/process.yaml`（2026-10-29 核对）。改革窗口期——points test 改革仍在讨论，评估模型待改革落地后按官方新表重建。

## 阶段

1. **职业评估**（3-6 个月）：按职业选机构（VETSESSESS/ACS/EA 等）
2. **语言考试**（3-6 个月）：雅思/PTE 等，达签证最低要求
3. **SkillSelect 提交 EOI**（数天）：按分数与职业入池排序
4. **等待邀请**（1-2 年）：按轮次发邀请，日期可能调整
5. **ITA 后 60 天递交**：体检、无犯罪、材料
6. **审批与 PR**（6-18 个月）：背景调查 → 批准 → 领卡

## 四层材料清单

- 通用：护照、语言成绩、工作推荐信、无犯罪、出生公证
- 国别：职业评估报告、EOI 提交记录
- 通路：ITA 60 天材料、体检表、州担保材料（190/491 按各州要求）
- 画像条件项：已婚 → 配偶材料；有子女 → 子女材料；职业评估未完成 → 提示先做评估
